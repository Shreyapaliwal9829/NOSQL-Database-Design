# Lab Sheet 01 — NoSQL Database Design

**Course:** BCA  
**Topic:** MongoDB / NoSQL Database Design

## Files
- `Lab-Sheet-01-NoSQL-Database-Design.js` — MongoDB Shell commands and guidance for all 25 practical questions.

## How to run
1. Install and start MongoDB, and open `mongosh`.
2. Open the `.js` file in a text editor.
3. Run the commands section by section in `mongosh`, or run the file with:
   `mongosh "mongodb://127.0.0.1:27017" --file "Lab-Sheet-01-NoSQL-Database-Design.js"`

## Important
- The code uses sample student data. You can change names, roll numbers, and departments.
- Practical 20 deletes the entire `StudentDB` database. The `db.dropDatabase()` line is commented out intentionally. Uncomment and run it only when you are ready to demonstrate that practical.
- Practical 17 renames `Students` to `StudentDetails`, so later practicals use the resulting database state.
- For practicals 22–25, the file includes guidance/comparison notes because those tasks also require work in MongoDB Compass and a written lab report.
- Record the actual outputs from your own system and take screenshots for your lab record.
